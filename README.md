## 主要版本



### main_FieldForecast_Unet_v1
🧭方案：
- 相比于原始版本增加了Dice Loss，用于摆脱统计指标限制，量化结果的相似性。

🪫目前主要问题在于：
- 预报结果大值偏小，小值偏大。
- 高分位 (Q0.99) bias ≈ -2.05（大值低估），低分位轻微偏差
 
### main_FieldForecast_Unet_v2
🧭方案：
- 学习率 (lr) 调度：固定 lr 易卡在局部最小，导致平滑。加ReduceLROnPlateau，渐降 lr 细化极端。
- 权重初始化：U-Net 默认 Xavier 偏保守，加 He 初始化（ReLU 友好）。
- 损失函数调整：针对极端值加权

🪫目前主要问题在于：
- 预报结果大值偏小，小值偏大。
- correlation coefficient偏小（比v1），误差偏大

#### main_FieldForecast_Unet_v3.2.1 & v3.2.2
🧭方案：

- 但由此带来的结果是风圈范围内的预测结果一塌糊涂。

#### main_FieldForecast_Unet_v3.2.3
🧭方案：
- 在v3.2.2激活函数GELu的基础上回退损失函数至融合MSE、梯度、分位数损失。

🪫结果：
- 最大值由v3.2.2的\~3.5降低至\~3.3，表明**激活函数貌似对结果影响不显著**。

### main_FieldForecast_Unet_v3.3.0
🧭方案：

- 增加了内存回收机制，极大减小了内存开销。

🪫结果：
- 重采样结果影响不显著，但有0.02m的提升。

💭想法：
- 重采样按说应该对结果有提升，但1314时刻的个例反应不出来，这不能代表方法有问题。
- 但是仍然需要继续调整。
